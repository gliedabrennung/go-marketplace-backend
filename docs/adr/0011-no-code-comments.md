# ADR-0011. Контракты вне комментариев в коде

**Статус:** Принято · **Дата:** 2026-09-15

## Контекст

По требованию заказчика исходный код пишется без комментариев. ТЗ (п. 9.3) предлагает документировать контракты интерфейсов комментариями.

## Решение

- В коде допускаются только обязательные директивы: `//go:build`, `//go:embed`, аннотации goose `-- +goose …`.
- Контракты портов (возвращаемые ошибки, гарантии) фиксируются:
  - именами типизированных ошибок (`ErrOrderNotFound`, `kernel.ErrConcurrentModification`);
  - contract-тестами, общими для всех реализаций интерфейса (п. 14.4 ТЗ);
  - разделом «Контракты портов» в `docs/contracts/<context>.md`.
- Правило `revive:exported` отключено; `_ = f()` не используется — ошибки обрабатываются явно.

## Последствия

- Описание поведения живёт в тестах и документации, которые проверяются CI и review.
