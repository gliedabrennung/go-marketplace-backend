# ADR-0013. Объектное хранилище: SeaweedFS с S3 API

**Статус:** Принято · **Дата:** 2026-09-16

## Контекст

FR-CT-08 требует загрузки изображений через presigned URL и генерации превью, FR-CT-07 — загрузки файлов пакетного импорта до 50 000 строк. NFR-SEC-07 запрещает принимать файлы через прикладной процесс без проверки типа по содержимому и требует отдачи через presigned URL. Нужен S3-совместимый бэкенд, который поднимается в dev-окружении одним контейнером.

## Решение

- Хранилище — SeaweedFS с включённым S3 API (`weed server -s3`), доступ по ключам из `s3.json`; клиент — `aws-sdk-go-v2` в `internal/shared/platform/objectstore` (path-style адресация, расчёт контрольных сумм `WhenRequired`).
- Конфигурация: `S3_ENDPOINT` (внутренний адрес для сервисов), `S3_PUBLIC_ENDPOINT` (адрес, попадающий в presigned URL), `S3_BUCKET`, ключи доступа. Бакет создаётся при старте `cmd/api`, готовность проверяется в `/readyz`.
- Загрузка изображения: `POST .../images` возвращает presigned `PUT` на 15 минут по ключу `catalog/products/{product_id}/images/{image_id}/original`; клиент загружает файл напрямую в хранилище.
- Подтверждение: `HEAD` (размер) + чтение первых 512 КБ и определение типа по содержимому (`http.DetectContentType` + декодирование заголовка JPEG/PNG/WebP). Несовпадение с заявленным типом или размером — `CATALOG_IMAGE_MISMATCH`.
- Превью генерирует `worker` по событию `catalog.product_image_uploaded.v1`: `small.jpg` (256 px) и `large.jpg` (1024 px), кодирование JPEG, защита от «бомб» — ограничение 50 Мп и 10 МБ.
- Отдача файлов — presigned `GET` на 1 час; анонимный доступ к бакету закрыт. Оригинал изображения виден только продавцу-владельцу и модератору.
- Файлы импорта и отчёты об ошибках лежат под `catalog/imports/{seller_id}/`; ключ, полученный не по этому префиксу, отклоняется доменом (`CATALOG_INVALID_OBJECT_KEY`).

## Последствия

- Одна зависимость в compose вместо MinIO; протокол — S3, поэтому замена на MinIO, Ceph RGW или облачный S3 сводится к смене конфигурации.
- Приложение не проксирует файлы: трафик идёт мимо процесса `api`, но presigned URL нельзя отозвать до истечения TTL.
- SeaweedFS не поддерживает часть расширенных возможностей S3 (например, политики бакета уровня AWS); права выдаются через `s3.json` идентичности.
