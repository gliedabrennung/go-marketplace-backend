# Контракты портов: shipping

До этапа 5 контекст представлен только портом тарифов (ADR-0017). Проверяется `internal/shipping/infrastructure/flat/tariffs_test.go`.

## Публичный контракт `internal/shipping/api`

| Метод | Контракт |
|-------|----------|
| `Tariffs.Quote(TariffRequest)` | стоимость по каждой посылке продавца и общая сумма в валюте запроса; пустой способ — `standard`; неизвестный — `SHIPPING_UNKNOWN_METHOD` |

## Временная реализация `flat`

| Параметр | Значение |
|----------|----------|
| `SHIPPING_FLAT_FEE` | стоимость одной посылки в минимальных единицах валюты |
| `SHIPPING_FREE_THRESHOLD` | сумма посылки после скидок, начиная с которой доставка бесплатна; `0` отключает порог |
