# Контракты портов: cart

Проверяются `test/integration/cart/repository_contract_test.go` (in-memory и PostgreSQL) и сквозным тестом `test/integration/ordering/checkout_test.go`.

## Репозиторий

| Метод | Контракт |
|-------|----------|
| `FindByOwner(owner)` | корзина пользователя или устройства с позициями в порядке добавления; иначе `ErrCartNotFound` |
| `Save` | одна корзина на владельца (`uq_carts_owner`), повторное создание — `ErrConcurrentModification`; оптимистичная блокировка по `version`; позиции перезаписываются целиком |
| `Delete` | удаляет корзину той же версии, иначе `ErrConcurrentModification` |
| `DeleteExpired(before, limit)` | удаляет анонимные корзины с истёкшим сроком; корзины пользователей не истекают |

## Правила корзины

| Правило | Реализация |
|---------|-----------|
| Владелец | авторизованный пользователь или устройство из заголовка `X-Device-ID` (16–128 символов `A-Za-z0-9_-`); без обоих — `CART_OWNER_REQUIRED` |
| Слияние (FR-CA-01) | `POST /api/v1/cart/merge` с `X-Device-ID`: количества суммируются в пределах остатка и лимита позиции, новые позиции добавляются до лимита, промокод пользователя приоритетнее, анонимная корзина удаляется |
| Лимиты (FR-CA-04) | до 100 позиций, количество 1–999 и не больше доступного остатка: `CART_TOO_MANY_ITEMS`, `CART_INVALID_QUANTITY`, `CART_QUANTITY_EXCEEDS_STOCK` |
| Доступность | оффер `active` у опубликованного товара и остаток > 0, иначе `CART_OFFER_UNAVAILABLE` |
| Валюта | все позиции в одной валюте |
| TTL (FR-CA-06) | анонимная корзина живёт 30 дней с последнего изменения; задача `cart.purge_expired` |

## Представление корзины

| Поле | Смысл |
|------|-------|
| `groups[]` | позиции по продавцам с суммой, скидкой, доставкой и итогом (FR-CA-05) |
| `items[].status` | `available`, `insufficient_stock`, `unavailable` (FR-CA-03) |
| `items[].saved_price`, `price_changed` | цена на момент добавления и признак её изменения (FR-CA-03) |
| `promo_error` | причина, по которой сохранённый промокод сейчас не применяется |
| `issues[]` | блокирующие проблемы: `CART_OFFER_UNAVAILABLE`, `CART_QUANTITY_EXCEEDS_STOCK` |
| `ready` | можно оформлять: нет проблем, промокод применим, итог > 0 |

Цены и скидки считает `pricing.Pricer.Quote` только по доступным позициям; позиция без цены в проекции `pricing` помечается недоступной. Доставка — порт `shipping/api.Tariffs` (ADR-0017). `POST /api/v1/cart/promo-code` сохраняет код только если котировка его принимает.

## Публичный контракт `internal/cart/api`

| Метод | Результат |
|-------|-----------|
| `Carts.Checkout(userID)` | состав корзины пользователя и промокод; пустая — `CART_EMPTY` |
| `Carts.RemoveOrdered(userID, skus)` | удаляет оформленные позиции; отсутствие корзины или позиций — без ошибки |
