# Контракты портов: search

Проверяются `test/integration/search/search_test.go` (PostgreSQL) и модульными тестами прикладного слоя.

## Index

| Метод | Результат |
|-------|-----------|
| `ActiveTable` / `InactiveTable` | имя версии таблицы документов из `search.index_state` |
| `SaveDocuments` | upsert документов в указанную версию таблицы; `tsvector` пересчитывается генерируемой колонкой |
| `SetCover` | обновление обложки опубликованного товара |
| `Truncate` / `Swap` | очистка неактивной версии и переключение view `search.documents` вместе с `index_state` |
| `SaveOffer` / `SaveSeller` | состояние офферов и право продавца на продажу |
| `SaveStock` | доступный остаток оффера из события `inventory.stock_changed.v1`; возвращает товар для пересчёта |
| `RefreshProduct` / `RefreshSeller` | пересчёт `search.product_stats`: минимальная цена, число офферов и продавцов, состояния товара; учитываются только активные офферы с `available > 0` у продавцов с `can_sell` |
| `RefreshLexicon` | словарь `search.lexicon` из `ts_stat` активной таблицы для исправления опечаток |

## ReindexJobs

| Метод | Результат |
|-------|-----------|
| `Create` | задание в статусе `pending`; повторный запрос при незавершённом задании — `SEARCH_REINDEX_RUNNING` |
| `Claim` | `FOR UPDATE SKIP LOCKED`: одно задание одному воркеру, статус `running` |
| `Progress` / `Finish` | число обработанных документов, финальный статус `completed` или `failed` с причиной |
| `Get` | задание или `SEARCH_REINDEX_JOB_NOT_FOUND` |

## ReadModel

| Метод | Результат |
|-------|-----------|
| `Search` | фильтры: категория (по всему поддереву), атрибуты (`код:значение|значение`), цена, продавец, состояние, наличие; сортировки `relevance`, `price_asc`, `price_desc`, `new`, `popular`; курсор кодирует ключ сортировки и `product_id` |
| `Facets` | счётчики значений атрибутов, диапазоны числовых атрибутов, состояния товара и диапазон цены по тому же набору фильтров |
| `Suggest` | ближайшее слово словаря по триграммной похожести не ниже порога |

## Поведение прикладного слоя

| Сценарий | Результат |
|----------|-----------|
| Нулевая выдача по непустому запросу | одна попытка исправления опечаток; при успехе ответ содержит `corrected_query` |
| Полная переиндексация | сборка в неактивной таблице → переключение view → догон изменений, произошедших во время сборки → обновление словаря |
| Права на переиндексацию | `catalog.categories.manage` |
| Наличие (`in_stock`) | есть хотя бы один активный оффер с доступным остатком (`inventory`) у продавца с правом продавать |
